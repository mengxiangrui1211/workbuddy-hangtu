# WorkBuddy 航海图

> 从第一项任务，到一支 AI 舰队。
> WorkBuddy 从零到精通的原创实战教程（VitePress 站点）。

本仓库是《WorkBuddy 航海图》的源码，结构与阅读体验参考了社区开源项目
[WorkBuddy 实战蓝皮书](https://github.com/AlephAITech/WorkBuddyGuide)（MIT），
但**全部正文为原创撰写**，并换用「航海图」品牌与海洋蓝青主题，不再沿用「蓝皮书」之名。

## 本地运行

```bash
npm install
npm run dev      # 本地预览 http://localhost:5173
npm run build    # 构建到 .vitepress/dist
npm run preview  # 预览构建产物
```

## 内容结构

- 第一篇 · 使用手册（CH1–10）：安装、界面、首个任务、Skill、专家、连接器、API、自动化
- 第二篇 · 案例篇（CH11–21）：办公、文件、远程、资讯、知识、会议、投资、视频、自媒体、GEO
- 第三篇 · 进阶篇（CH22–25）：打造 Skill、多 Agent、自动化可靠性
- 第四篇 · 岗位与行业（CH26–27）：岗位路线、行业路线
