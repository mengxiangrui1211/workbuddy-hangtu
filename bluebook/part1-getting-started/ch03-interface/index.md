# 第 3 章 WorkBuddy 的主界面、任务与工作区

打开客户端，你会看到一个分成几个区域的工作台。先认识它们，后面才不会迷路。

## 主界面三块

```
┌─────────────┬──────────────────────────┬──────────────┐
│  侧边栏      │      对话 / 任务区          │   结果区       │
│  (导航/历史) │      (你下指令、它执行)      │  (产物/文件/预览)│
└─────────────┴──────────────────────────┴──────────────┘
```

- **侧边栏**：历史任务、技能、连接器、设置的入口。
- **对话 / 任务区**：你输入需求、它拆解步骤并汇报进展的地方。
- **结果区**：右侧查看生成的文件、变更、预览。

## 任务（Task）是什么

一个**任务** = 你给的一次目标 + WorkBuddy 围绕它完成的一连串动作。

- 每个任务有独立上下文，互不影响。
- 任务有状态：进行中 / 已完成 / 等待你确认。
- 你可以随时回到旧任务继续推进。

::: tip 用好任务列表
把不同目标拆成不同任务，比在一个长对话里堆所有事更好——上下文更干净，也更容易复用和复盘。
:::

## 工作区（Workspace）

- 工作区是任务产物的默认落盘目录。
- 同一工作区内的文件、记忆可以共享。
- 复杂项目建议一个项目一个工作区。

## 顶部操作

对话区顶部通常能：上传文件、切换模式、引用资料、查看进度。

::: info 记住这个循环
**下指令 → 看它拆解执行 → 在结果区验收产物 → 不满意就接着说**。这个循环会贯穿你使用 WorkBuddy 的每一天。
:::
