# 第 1 章 初识 WorkBuddy

WorkBuddy 是腾讯出品的**全场景 AI 办公工作台**。一句话描述它的不同：普通 AI 聊天工具「给你建议」，WorkBuddy「替你把事办了」。

## 它和你用过的 AI 对话，差在哪

| 传统 AI 对话 | WorkBuddy |
| --- | --- |
| 只能对话、给建议 | 能实际执行任务、交付产物 |
| 你手动复制结果、自己操作文件 | 自动读写你授权的本地文件 |
| 一次一个问题 | 自主拆解多步骤复杂任务 |
| 产出一段文字 | 交付可验收的结果（文档/表格/图/代码） |

## 四个核心能力

1. **理解自然语言**：用大白话下任务，不用记命令。
2. **自主规划执行**：自动把大目标拆成步骤，并一步步做。
3. **多模态任务处理**：文档、表格、PPT、数据分析、图片都能接。
4. **本地文件操作**：在授权范围内批量处理你电脑里的文件。

## 它适合什么

- 文档生成：工作报告、技术文档、会议纪要
- 数据分析：上传数据文件，自动分析并出图
- 演示文稿：从一句话需求生成 PPT
- 深度研究：对复杂问题调研并输出报告
- 批量文件处理：整理、重命名、格式转换

::: warning 边界意识
WorkBuddy 能力很强，但**对外发布、金额交易、隐私数据**这类动作，建议先划清边界再让它动手。后面每章都会提示对应的安全边界。
:::

## 一句话建立心智模型

> WorkBuddy = 一个会自己干活、能调用工具、还能组队的 AI 同事。
> 你负责定目标和验收，它负责过程和产物。
