# 课外补给：一章看懂 AI 工作系统

前面 10 章教你把 WorkBuddy 用起来。这一章给你一张「全局地图」，后面所有案例和进阶，都挂在它上面。

## 四个层级

```
TASK ──▶ CASE ──▶ WORKFLOW ──▶ AI TEAM
 任务      案例      工作系统       AI 团队
```

### ① TASK：完成一个真实任务
最低起点。你下指令，它交付一个可验收的结果。
> 例：把这份录音转成会议纪要。

### ② CASE：复盘成可复现案例
把「成功的那次」写清楚：用了什么 Skill、提示词怎么写、验收标准是什么。
> 价值：下次不用从头想，照着做就能复现。

### ③ WORKFLOW：沉淀为 Skill 与自动化
把高频 CASE 固化：做成 **Skill**（一键调用），或做成**自动化**（定时/触发自己跑）。
> 价值：从「每次手动」变成「系统替你跑」。

### ④ AI TEAM：组合成协作团队
多个 Skill / 专家 / Agent 编排在一起，处理单兵搞不定的复杂目标。
> 例：调研 Agent 找资料 → 写作 Agent 出稿 → 设计 Agent 做图 → 审核 Agent 把关。

## 为什么是「系统」而不是「工具」

工具解决一次问题；系统让成功**可复制、可协作、可迭代**。

- 工具：你今天让 AI 写了份报告。
- 系统：你有一套「每周自动出报告、出错会告警、换人也能跑」的机制。

## 一本航海图的读法

- 第一篇 = 学会 **TASK**。
- 第二篇 = 积累 **CASE**（大量真实场景）。
- 第三篇 = 升级到 **WORKFLOW**（Skill / 多 Agent / 可靠自动化）。
- 第四篇 = 落地成 **AI TEAM**（岗位与行业）。

::: tip 从现在开始
每完成一个还不错的 TASK，顺手记成 CASE。三个月后，你会拥有一套别人没有的工作系统。
:::
