# 第 2 章 下载、安装、登录与更新

先把船造好，才能出海。

## 下载与安装

1. 前往 WorkBuddy 官方渠道获取安装包（Windows / macOS）。
2. 双击安装包，按引导完成安装。
3. 首次启动会要求登录：使用你的腾讯账号扫码或授权登录。

::: tip 登录后第一次要做的事
登录后先确认两件事：**工作区目录**在哪里（任务产物默认存这），以及**是否授权了本地文件读取**（后面批量处理文件会用到）。
:::

## 三种工作模式

WorkBuddy 在对话时有三种模式，理解它们能少走很多弯路：

| 模式 | 行为 | 适合 |
| --- | --- | --- |
| **Craft（你说，我做）** | 立即动手执行任务 | 明确要产出东西时 |
| **Plan（先想后做）** | 先出方案，你确认后再执行 | 复杂、有风险的改动 |
| **Ask（只聊不动）** | 只回答、分析，不写文件不跑命令 | 咨询、选型、学习 |

切换方式通常在输入框附近或模式菜单里。新手默认用 **Craft** 即可。

## 更新

- 客户端一般会提示更新；也可在「设置 / 关于」里手动检查。
- 保持较新版本，能用到最新的 Skill、连接器和模型能力。

::: warning 版本差异
界面文案、功能入口可能随版本变化。如果本文某处和你看到的界面不一致，以你客户端当前版本为准，并到 [官方文档](https://www.workbuddy.cn/docs/workbuddy/Overview) 核对。
:::
