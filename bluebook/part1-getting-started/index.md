# 第一篇 · 使用手册：先把 WorkBuddy 用起来

这一篇的目标只有一个：**让你在 30 分钟内真正用起来**，并完成第一项能验收的任务。

我们不急着讲所有功能。先把最小闭环跑通——安装、认识界面、发第一个任务、加载一个 Skill、连接一个常用工具、设一个自动化——剩下的案例和进阶，都是在这个闭环上长出来的。

## 本篇路线

| 章节 | 你会学到 |
| --- | --- |
| 第 1 章 | WorkBuddy 到底是什么，和传统 AI 对话有什么不同 |
| 第 2 章 | 下载、安装、登录与更新 |
| 第 3 章 | 主界面、任务与工作区 |
| 第 4 章 | 快速完成第一个任务（拿到可验收结果） |
| 第 5 章 | 加载一个真正用得上的 Skill |
| 第 6 章 | 专家和专家团 |
| 第 7 章 | 使用连接器（MCP）打通外部工具 |
| 第 8 章 | 接入小程序与 IM 助理 |
| 第 9 章 | 如何接入外部 API |
| 第 10 章 | 自动化任务，让重复的事自己跑 |
| 课外补给 | 一章看懂 AI 工作系统（贯穿全书的思维模型） |

::: tip 新手建议
