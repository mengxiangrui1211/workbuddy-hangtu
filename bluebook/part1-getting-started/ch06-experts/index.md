Skill 是「能力外挂」，**专家（Expert）** 是「领域老手」。当你的问题需要专业纵深（法律、财务、医疗、编程规范……），直接找对应专家更靠谱。

## 专家是什么

- 专家是经过领域化训练的对话角色，掌握该行业的术语、规则和常见做法。
- 平台内置 **100+ 领域专家**，覆盖法律、金融、医疗、研发、运营等。

## 怎么用

1. 从「专家中心」按分类浏览，或直接搜索。
2. 进入某个专家，像聊天一样提问；它会按该领域的专业方式回应。
3. 复杂目标可把多个专家**组成专家团**协作（类似多 Agent，见第三篇）。

## 例子

- 写合同前，先问「法务专家」理清条款边界。
- 做投放前，问「增长专家」定指标和漏斗。
- 代码评审前，问「架构专家」看设计。

::: tip 专家 vs Skill 怎么选
- 要**专业判断 / 咨询** → 用专家。
- 要**固定流程的产出** → 用 Skill。
- 两者常配合：专家定方案，Skill 出产物。
:::

::: warning 专家不是法律/医疗终裁
涉及合规、诊断、签约等高风险事项，专家输出仅供参考，最终以持证专业人士意见和官方渠道为准。
:::
