**场景**：你想做一条短视频，但脚本、配音、画面、剪辑样样要人，一个人搞不动。

**用到的能力**：多 Agent / 专家团、视频生成 Skill、跨工具闭环。

## 任务描述

```
做一条 60 秒的科普短视频：主题「AI 办公到底省了什么」。
分工：
- 脚本 Agent：写分镜脚本（钩子/干货/结尾）。
- 画面 Agent：用文生图/图生视频生成每镜画面。
- 配音 Agent：生成旁白音频。
- 剪辑 Agent：合成成片并加字幕。
产出：一个 mp4 + 一页分镜表。先给我看分镜，确认后再生成视频。
```

## 验收标准

- [ ] 分镜先过目，再出片（避免返工）
- [ ] 成片有字幕、节奏连贯
- [ ] 产出分镜表，方便二次修改

::: tip 这是「AI 团队」的雏形
单个任务拆给多个 Agent 协作，正是第四篇要讲的多 Agent 系统。先在这里感受「派活给团队」的节奏。
:::

::: warning 先确认再量产
视频生成耗资源。务必先看分镜/脚本，确认方向对，再生成最终视频，省时省钱。
:::

::: info 沉淀
把这条流水线固化成你的「视频生产 Skill」，下次换个主题直接跑。
:::
