**场景**：你关注 5 个领域，但没空每天刷。希望每天一睁眼，重要更新已经整理好推给你。

**用到的能力**：联网搜索 / RSS 连接器、自动化、IM 推送。

## 任务描述（做成一个每日自动化）

```
每天早 8:00：
1. 搜索过去 24 小时关于「AI 办公 / 腾讯云 / 自动化」的重要动态。
2. 各取 3 条最相关的，标注来源与时间。
3. 过滤掉广告和旧闻重发。
4. 整理成一份 5 条内的简报，推送到飞书我的会话。
```

## 验收标准

- [ ] 每天准时推送
- [ ] 条目带来源、可溯源
- [ ] 无重复/广告噪音

::: tip 给它「筛选标准」
告诉它你眼里什么是「重要」：影响工作流？有具体数字？竞品动作？标准越清楚，简报越准。
:::

::: warning 别全信聚合
自动抓取的资讯可能遗漏或误判。重要决策前，点来源原文复核。
:::

::: info 进阶
把「简报」沉淀成 Skill，加一个「本周热点周报」变体，资讯系统就成型了。
:::
