# 第 12 章 从整理桌面文件这些小事做起

**场景**：桌面堆了 300 个文件，命名乱、类型杂，找个东西要翻半天。

**用到的能力**：本地文件读取、批量重命名、按类型/日期归类。

## 任务描述

```
整理我桌面的「下载」文件夹：
1. 按类型分到 图片/文档/压缩包/其他 四个子目录。
2. 图片按「拍摄年月」再细分（如 2026-07）。
3. 重命名规则：原文件名前加日期前缀 YYYYMMDD-。
4. 列出 10 个最大的文件，告诉我有没有可清理的大文件。
只整理，不删除任何文件。
```

## 验收标准

- [ ] 文件按类型归位，无遗漏
- [ ] 重命名前缀格式统一
- [ ] 给出「大文件清单」供我人工决定

::: danger 整理 ≠ 删除
明确告诉它「只整理、不删除」。批量删除高风险，确认无误再手动清。桌面/下载属于个人目录，更要谨慎（参考安全规则）。
:::

::: tip 先小范围试
第一次可让它只在**一个测试文件夹**里跑，确认逻辑对，再放开到真实目录。
:::

::: info 沉淀成 CASE
这套「按类型+日期归类+不删除」的提示词，跑顺后可以存成你自己的文件整理 CASE，下次直接复用。
:::
