**场景**：旅游攻略、健身计划、送礼清单、聚餐点菜——这些小事单独做不值当，堆一起很耗神。

**用到的能力**：对话规划、联网搜索、IM 推送。

## 任务描述

```
帮我规划这周六的一日游（城市：杭州，2 人，预算 600，
喜欢自然风光和咖啡，中午想吃杭帮菜）。
输出：时间轴行程表 + 每个点的备注（门票/人均/交通）。
```

## 还能做

- 周训练计划：「每周三练，在家，无器械，目标减脂」。
- 送礼清单：「送 30 岁男性程序员，预算 200，实用向」。
- 聚餐点菜：「6 人，2 个不吃辣，要有硬菜和素菜」。

## 验收标准

- [ ] 计划具体到「时间 / 地点 / 备注」
- [ ] 预算、偏好约束都被满足

::: tip 把偏好一次说清
人數、预算、忌口、喜好——一次给全，少来回。这些也可以沉淀成「我的偏好」CASE，以后提一句就行。
:::

::: info 生活也能自动化
「每周日 20:00 给我下周的健身+饮食计划」——这种规律性生活事务，直接做成自动化。
:::
