**场景**：周五下午，老板要一份 Q3 复盘 PPT、一张数据表、一段总结稿。你只有一堆散乱要点。

**用到的能力**：文档生成、数据分析、PPT 生成、结果区预览。

## 任务描述（可直接复制）

```
帮我做一份 Q3 复盘材料包：
1. 一份 PPT（8 页内）：封面、业绩概览、亮点、问题、下季度计划。
2. 一张 Excel：各月营收、环比、达成率（用我给的数据）。
3. 一段 200 字总结稿，给老板口头汇报用。
数据：1月120,2月135,3月150,4月148,5月162,6月180（万元），目标线150。

验收：PPT 能直接讲；表格有公式算环比和达成率；总结稿不超 200 字。
```

## 你会拿到什么

- 结果区出现 `.pptx` / `.xlsx` / 文档，可预览和下载。
- Excel 里环比、达成率已用公式算好，不是写死的数值。

## 验收标准

- [ ] PPT 结构完整、可直接演示
- [ ] 表格公式正确（改一个数，环比跟着变）
- [ ] 总结稿字数达标、重点突出

::: tip 让它更对路
给数据时顺手给**目标线、口径、受众**，产物会专业很多。「给老板看」和「给团队看」写法完全不同。
:::

::: warning 数字要复核
AI 算的环比/占比偶尔会算错。对外发布前，自己抽两行验算一下。
:::
