# 第 13 章 远程控制你的电脑，不用发愁不在电脑前

**场景**：人在外面，需要家里/公司电脑上的某个文件，或要它跑个长任务。

**用到的能力**：远程控制连接器（如向日葵类）、IM 助理、自动化。

## 方案

1. 在 WorkBuddy 里连上远程控制连接器，并授权目标设备。
2. 通过 IM / 小程序远程下指令：

```
我不在电脑前。帮我连上家里那台 Windows，
把「项目/合同」目录里最新的 PDF 发到飞书我的会话，
然后关机。只做这一件，做完就停。
```

## 验收标准

- [ ] 文件确实出现在你的 IM
- [ ] 操作后设备按预期关机/休眠，没有误关别的

::: danger 远程 = 高权限
远程控制能操作整台电脑。**只连你自己的设备**，指令尽量「单一、明确、可撤销」，避免「帮我随便整理下」这种开放式指令。
:::

::: tip 配合自动化
把「每天下班自动备份桌面到云盘」之类做成自动化，比临时远程更稳。
:::

::: warning 网络安全
在可信网络下使用远程控制；公共 Wi-Fi 下尽量只做读取、不做写操作。
:::
