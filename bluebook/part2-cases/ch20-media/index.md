**场景**：你做自媒体，但选题靠拍脑袋、标题随便起、发了没数据就焦虑。

**用到的能力**：选题研究、标题生成、封面 Skill、视频生成、合规审查、复盘。

## 一条增长闭环

```
选题 → 标题/封面 → 内容生产 → 发布 → 数据复盘 → 反哺选题
```

## 任务描述（串联起来）

```
围绕「职场效率」赛道，帮我跑一轮：
1. 选题：给 5 个本周可做的选题，带搜索热度判断。
2. 对选中的选题，出 3 个标题（不同钩子）和一张封面方案。
3. 生成一条 60 秒口播脚本。
4. 发布前做合规检查（平台违禁词、事实核查）。
5. 一周后，若我贴数据，帮我复盘哪类选题表现好。
```

## 验收标准

- [ ] 选题有依据，不是空想
- [ ] 标题/封面有差异化
- [ ] 发布前有合规把关

::: tip 闭环 > 单篇爆款
单次爆款靠运气，闭环靠系统。把每一步固化，你的账号才「可复制地增长」。
:::

::: warning 合规是底线
医疗、理财、时政等敏感领域，发布前必须事实核查、规避违禁词，必要时人工终审。
:::

::: info 自动化
把「每周一定期产出下周选题+标题库」做成自动化，灵感不会断。
:::
