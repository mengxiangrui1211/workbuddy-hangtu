**场景**：你关心几只标的，但每天手动翻行情、新闻太累，容易凭感觉决策。

**用到的能力**：金融数据连接器 / API、联网搜索、固定模板、自动化。

::: warning 不是投资建议
以下仅演示「信息处理自动化」，不构成任何投资建议。真实交易请以持牌机构和你自身风险承受为准。
:::

## 任务描述（做成每日例行）

```
每个交易日收盘后：
1. 拉取我关注的标的（AAPL/腾讯/茅台）当日涨跌、成交量。
2. 搜当日相关重大新闻各 2 条，标来源。
3. 按固定模板出一份「观察笔记」：数据表 + 新闻摘要 + 我的备注栏（留空给我写）。
只整理信息，不做买卖建议。
```

## 验收标准

- [ ] 数据带单位、可核对
- [ ] 新闻有来源、分标的
- [ ] 明确「不荐股」，留人工判断位

::: tip 把它当「第二双眼睛」
目标是让你**不漏关键信息**，不是替你决策。把判断权留给自己。
:::

::: danger 隐私与合规
别把账户、持仓等敏感信息明文丢给不可信的对话；涉及实盘请走合规渠道。
:::
