**场景**：收藏夹 200 篇「以后看」，从未再看。真正需要时，还是现搜。

**用到的能力**：知识库连接器（如 ima / Obsidian）、提炼、检索式复用。

## 换个姿势

不是「存进去」，而是「存成能检索的结构」：

```
把我贴的这篇关于「自动化测试」的文章，提炼成：
1. 3 个核心观点
2. 可照搬的 5 条实践清单
3. 用一句话记什么时候该用
存入我的知识库，标签：测试/工程效能。
```

## 验收标准

- [ ] 内容被提炼，不是原文搬运
- [ ] 带了可检索的标签 / 索引
- [ ] 之后用「测试 实践清单」能搜到

::: tip 管理 = 能复用
知识管理的最终检验是：**下次遇到同类问题，你能一句话把它调出来用**。做不到这点，收藏只是数字囤积。
:::

::: info 连接你的工具
把知识库连进 WorkBuddy，以后写方案时它可以直接引用你库里的材料，而不是凭空编。
:::

入库时保留原文链接，方便追溯和核对时效。
:::
