# 第 21 章 WorkBuddy 也能做 GEO 专家

**场景**：你做了内容、投了广告，但在「AI 搜索」（如各类对话式助手）里搜不到你。这时代需要 **GEO（Generative Engine Optimization，生成式引擎优化）**。

**用到的能力**：GEO 专家 / 研究框架、联网检索、报告生成。

## 什么是 GEO

传统 SEO 是「让搜索引擎排前面」；GEO 是「让 AI 在回答时引用你」。核心：结构化、可信、可被引用的内容。

## 任务描述

```
以「我的品牌 XX（做 AI 办公 SaaS）」为对象，做一次 GEO 诊断：
1. 用 AI 搜索视角，列出用户可能怎么问到我们这类产品（10 个真实问法）。
2. 诊断：我们的官网/内容在这 10 个问法下，被引用的可能性打分（0–5）。
3. 指出 3 个最该补的内容缺口（如对比评测、术语解释、案例）。
4. 产出一份改进清单（按优先级）。
输出：诊断报告（含评分表 + 缺口 + 行动项）。
```

## 验收标准

- [ ] 问法贴近真实搜索意图
- [ ] 评分有依据，不是拍脑袋
- [ ] 行动项可落地、有先后

::: tip GEO 的内容心法
AI 偏好**清晰定义、数据支撑、来源可查**的内容。把干货写成「可被引用的一段」，比堆关键词有用。
:::

::: info 闭环
诊断 → 补内容 → 再诊断。把这套做成周期性 CASE，你的「被 AI 引用率」会持续提升。
:::

::: warning 别刷量
GEO 靠真实价值与结构，不靠伪造来源。虚假信息一旦被 AI 引用，反噬品牌。
:::
