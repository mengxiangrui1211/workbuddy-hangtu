**场景**：两小时会开完，纪要有了，但没人跟进，两周后同样的问题又吵一遍。

**用到的能力**：会议纪要、待办提取、PRD 草稿、IM 推送。

## 任务描述

```
基于这份会议录音/纪要：
1. 产出标准会议纪要（结论/待办/开放问题）。
2. 待办拆成「负责人 + 截止 + 验收标准」的表格。
3. 其中「要做数据看板」这条，扩写成一页 PRD 草稿（背景/目标/范围/里程碑）。
4. 把待办表推送到项目飞书群。
```

## 验收标准

- [ ] 待办表有权责和验收，不是「跟进一下」
- [ ] PRD 草稿结构完整、可直接评审
- [ ] 团队已收到待办

::: tip 会议前就定「产出」
开会前告诉 WorkBuddy 你要什么产物（纪要？待办？PRD？），会比会后补救准得多。
:::

::: warning 别自动发错群
推送到群前确认群对了、内容脱敏了。涉及人事/薪资/机密的不进群。
:::

::: info 自动化延伸
「会议结束 → 自动出待办并建跟踪」做成自动化，会议闭环就稳了。
:::
