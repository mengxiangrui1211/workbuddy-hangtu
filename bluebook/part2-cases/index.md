# 第二篇 · 案例篇：从一项任务到一支 AI 团队

第一篇让你跑通了最小闭环。这一篇用 **11 个真实场景**告诉你：WorkBuddy 在工作里到底能替你扛多少。

每个案例都按同一套格式写，方便你直接照做、再沉淀成自己的 CASE：

- **场景与问题**：谁、在什么任务卡住
- **用到的能力**：Skill / 连接器 / 专家
- **任务描述**：可直接复制的提示词
- **验收标准**：怎样算做对了
- **边界提示**：哪里要小心
