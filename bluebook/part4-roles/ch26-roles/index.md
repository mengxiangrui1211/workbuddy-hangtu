# 第 26 章 岗位路线图：不同岗位如何把 WorkBuddy 用深

同一套能力，不同岗位用法不同。下面给几条高频岗位的「用深」路线。

## 产品经理
- 需求：把模糊想法写成 PRD 草稿（背景/目标/范围/里程碑）。
- 调研：竞品速览（第 23 章 CASE D）、用户反馈聚类。
- 会议：录音→纪要→待办→PRD 闭环（第 17 章）。
- 沉淀 Skill：`prd-drafter`、`competitor-scan`。

## 研发工程师
- 代码审查助手（CASE B）、脏数据清洗（CASE C）。
- 接 GitHub 连接器：查 PR、读 issue、跑流水线。
- 把「接某个内部 API」做成 MCP 连接器（第 9 章）。
- 沉淀 Skill：`code-reviewer`、`api-client`。

## 运营 / 市场
- 自媒体增长闭环（第 20 章）、GEO 诊断（第 21 章）。
- 资讯简报自动化（第 15 章）。
- 沉淀 Skill：`content-calendar`、`geo-audit`。

## 销售 / 商务
- 客户跟进：把聊天记录整理成跟进表 + 下一步。
- 提案：基于模板一键生成方案初稿。
- 竞品与报价速览。

## 职能（HR / 财务 / 行政）
- HR：JD 起草、面试纪要、候选人对比表。
- 财务：发票整理与登记（第 12 章思路）、报销核对。
- 行政：会议纪要、日程冲突检查、物资清单。

::: tip 用深的标志
不是「用得频繁」，而是「**把你的高频动作做成了 Skill / 自动化**」——别人还在手搓，你已一键。
:::

::: warning 涉密岗位要划界
HR/财务/法务涉及个人信息与机密，务必脱敏、限定范围、人工终审，别让 AI 直接对外发。
:::
