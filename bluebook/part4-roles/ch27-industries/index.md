# 第 27 章 行业路线图：从通用能力到行业工作流

岗位是「角色」，行业是「土壤」。把通用能力塞进行业语境，才会长出真正落地的「行业工作流」。

## 一条通用迁移路径

```
通用能力 ──▶ 行业语料/规则 ──▶ 行业 Skill ──▶ 行业自动化 ──▶ 行业 AI 团队
```

1. **喂行业语境**：把行业术语、合规要求、常用模板连进知识库（第 16 章）。
2. **做行业 Skill**：如「保险条款解读」「病历结构化」「法条检索」。
3. **定行业自动化**：如「每日监管动态简报」「每周合规自查」。
4. **组行业团队**：调研 Agent + 写作 Agent + 合规审核 Agent 协作。

## 几个行业示意

| 行业 | 典型工作流 | 关键约束 |
| --- | --- | --- |
| 金融 | 投研简报、合规自查 | 合规、不荐股、数据溯源 |
| 法律 | 法条检索、合同审查、类案比对 | 保密、人工终审、不替代律师 |
| 教育 | 教案生成、作业批改、学情摘要 | 因材施教、隐私（未成年） |
| 电商 | 选品分析、详情页、客服话术 | 广告法、违禁词 |
| 医疗 | 文献综述、病历结构化 | 隐私、不替代诊断 |

## 验收：一个行业工作流「落地」的标志

- [ ] 用了行业术语与规则，不是通用套话
- [ ] 含合规/隐私边界，且执行时被遵守
- [ ] 能脱离你本人稳定运行（自动化 + Skill）

::: danger 强监管行业，AI 是辅助不是终裁
医疗诊断、法律意见、金融建议等，AI 产出仅作参考，最终由持证专业人士负责。务必保留人工终审与可追溯来源。
:::
